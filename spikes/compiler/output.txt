
=== Case 1 simple metric, booking-branch join, month grain
request: {'metric': 'disbursement_amount', 'dimensions': ['branch.region_name'], 'grain': 'month', 'start': '2026-01-01', 'end': '2026-07-01'}
--- Trino SQL
SELECT
  CAST(DATE_TRUNC('MONTH', "t0"."disbursement_date") AS DATE) AS "metric_time",
  "t1"."region_name" AS "branch__region_name",
  SUM("t0"."principal_amount") AS "disbursement_amount"
FROM "lending"."core"."contracts" AS "t0"
LEFT JOIN "lending"."core"."branches" AS "t1"
  ON "t0"."booking_branch_id" = "t1"."branch_id"
WHERE
  (
    NOT "t0"."disbursement_date" IS NULL
  )
  AND "t0"."disbursement_date" >= CAST('2026-01-01' AS DATE)
  AND "t0"."disbursement_date" < CAST('2026-07-01' AS DATE)
GROUP BY
  CAST(DATE_TRUNC('MONTH', "t0"."disbursement_date") AS DATE),
  "t1"."region_name"
ORDER BY
  "metric_time",
  "branch__region_name"
LIMIT 1000
--- explanation
  - disbursement_amount: join branch via contract.booking_branch (The branch that originated the contract. Never changes. Used for sales and disbursement metrics.)
  - disbursement_amount: keep rows where disbursement_date IS NOT NULL (part of the measure definition)
  - disbursement_amount: time is contract.disbursement_date, from 2026-01-01 up to but not including 2026-07-01

=== Case 4 ratio across two fact tables (payments / schedules), multi-hop joins, two dimensions, month grain
request: {'metric': 'collection_rate', 'dimensions': ['branch.region_name', 'product.financing_scheme'], 'grain': 'month', 'start': '2026-01-01', 'end': '2026-07-01'}
--- Trino SQL
WITH m_collected_amount AS (
  SELECT
    CAST(DATE_TRUNC('MONTH', "t0"."posting_date") AS DATE) AS "metric_time",
    "t2"."region_name" AS "branch__region_name",
    "t3"."financing_scheme" AS "product__financing_scheme",
    SUM("t0"."principal_paid" + "t0"."interest_paid") AS "collected_amount"
  FROM "lending"."core"."payments" AS "t0"
  LEFT JOIN "lending"."core"."contracts" AS "t1"
    ON "t0"."contract_id" = "t1"."contract_id"
  LEFT JOIN "lending"."core"."branches" AS "t2"
    ON "t1"."servicing_branch_id" = "t2"."branch_id"
  LEFT JOIN "lending"."core"."products" AS "t3"
    ON "t1"."product_id" = "t3"."product_id"
  WHERE
    (
      NOT "t0"."is_reversed"
    )
    AND "t0"."posting_date" >= CAST('2026-01-01' AS DATE)
    AND "t0"."posting_date" < CAST('2026-07-01' AS DATE)
  GROUP BY
    CAST(DATE_TRUNC('MONTH', "t0"."posting_date") AS DATE),
    "t2"."region_name",
    "t3"."financing_scheme"
), m_due_amount AS (
  SELECT
    CAST(DATE_TRUNC('MONTH', "t0"."due_date") AS DATE) AS "metric_time",
    "t2"."region_name" AS "branch__region_name",
    "t3"."financing_scheme" AS "product__financing_scheme",
    SUM("t0"."installment_amount") AS "due_amount"
  FROM "lending"."core"."installment_schedules" AS "t0"
  LEFT JOIN "lending"."core"."contracts" AS "t1"
    ON "t0"."contract_id" = "t1"."contract_id"
  LEFT JOIN "lending"."core"."branches" AS "t2"
    ON "t1"."servicing_branch_id" = "t2"."branch_id"
  LEFT JOIN "lending"."core"."products" AS "t3"
    ON "t1"."product_id" = "t3"."product_id"
  WHERE
    (
      "t0"."is_current"
    )
    AND "t0"."due_date" >= CAST('2026-01-01' AS DATE)
    AND "t0"."due_date" < CAST('2026-07-01' AS DATE)
  GROUP BY
    CAST(DATE_TRUNC('MONTH', "t0"."due_date") AS DATE),
    "t2"."region_name",
    "t3"."financing_scheme"
), unioned AS (
  SELECT
    "metric_time",
    "branch__region_name",
    "product__financing_scheme",
    "collected_amount" AS "collected_amount",
    NULL AS "due_amount"
  FROM m_collected_amount
  UNION ALL
  SELECT
    "metric_time",
    "branch__region_name",
    "product__financing_scheme",
    NULL AS "collected_amount",
    "due_amount" AS "due_amount"
  FROM m_due_amount
), combined AS (
  SELECT
    "metric_time",
    "branch__region_name",
    "product__financing_scheme",
    COALESCE(MAX("collected_amount"), 0) AS "collected_amount",
    COALESCE(MAX("due_amount"), 0) AS "due_amount"
  FROM unioned
  GROUP BY
    "metric_time",
    "branch__region_name",
    "product__financing_scheme"
)
SELECT
  "metric_time",
  "branch__region_name",
  "product__financing_scheme",
  "collected_amount",
  "due_amount",
  CAST("collected_amount" AS DOUBLE) / NULLIF("due_amount", 0) AS "collection_rate"
FROM combined
ORDER BY
  "metric_time",
  "branch__region_name",
  "product__financing_scheme"
LIMIT 1000
--- explanation
  - collected_amount: join contract via payment.contract (The contract the payment was made against.)
  - collected_amount: join branch via contract.servicing_branch (The branch that currently services and collects the contract. Changes when a customer is transferred. Used for portfolio and collection metrics.)
  - collected_amount: join product via contract.product (The financing product of the contract.)
  - collected_amount: keep rows where NOT is_reversed (part of the measure definition)
  - collected_amount: time is payment.posting_date, from 2026-01-01 up to but not including 2026-07-01
  - due_amount: join contract via installment.contract (The contract this installment belongs to.)
  - due_amount: join branch via contract.servicing_branch (The branch that currently services and collects the contract. Changes when a customer is transferred. Used for portfolio and collection metrics.)
  - due_amount: join product via contract.product (The financing product of the contract.)
  - due_amount: keep rows where is_current (part of the measure definition)
  - due_amount: time is installment.due_date, from 2026-01-01 up to but not including 2026-07-01
  - collection_rate = collected_amount / due_amount; each side is aggregated separately, then combined on ['metric_time', 'branch__region_name', 'product__financing_scheme']; a zero denominator gives NULL
